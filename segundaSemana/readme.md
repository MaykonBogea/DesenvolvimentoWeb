# 📌 Entregável de Desenvolvimento Web – Estilização do Formulário de Inscrição – Semana 02

O que deve ser entregue?

Finalização da estilização do formulário de inscrição do blog, aplicando conceitos de CSS para criar um layout organizado, visualmente agradável e com boa usabilidade.

O formulário deve apresentar:

Um container com largura máxima, padding e background-color diferente do fundo da página;

Uso de display: flex, flex-direction: column e gap para organizar os campos, um embaixo do outro;

Estilização dos elementos <label>, <input> e <select>, aplicando padding, border, border-radius e font-size;

Botão de enviar com destaque visual, utilizando background-color, color, padding e cursor: pointer;

Bônus: aplicação de display: flex e justify-content: space-between para colocar os campos de nome e e-mail lado a lado.

Certifique-se de que o arquivo esteja com as permissões de acesso liberadas para visualização.

Objetivo da atividade

A construção dessas etapas ajudará a equipe a aplicar os fundamentos de estilização com CSS, compreendendo como estruturar o layout de formulários utilizando Flexbox. Isso permite desenvolver interfaces mais organizadas, legíveis e atrativas para o usuário, melhorando a experiência de preenchimento e a identidade visual do projeto.

💡 Dica: Comece de fora para dentro: primeiro o espaço geral do container, depois cada campo. Adicione um button:hover { ... } para dar um ótimo acabamento no botão de enviar.
